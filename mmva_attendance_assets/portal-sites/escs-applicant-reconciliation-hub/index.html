Matching guide

  1. Check identity. Compare name variants, vacancy and authorised contact identifiers. Keep same-name applications separate until corroborated.
  2. Compare dates. Record the Indeed application, mailbox notification, Jotform completion and Monday creation dates separately. Check for later completion.
  3. Review source evidence. Save references to the Indeed application, original mailbox thread, Jotform submission and Monday item. Record the search scope and time when evidence is absent.
  4. Classify the outcome. Keep missing, unchecked and conflicting evidence distinct. Use Completed once required evidence is reconciled and follow-up is closed.

Outcome rules

No notification name match found

A scoped mailbox search found no matching name. Record the query and dates.

Name-only possible match

The name aligns but contact evidence is absent or inconclusive.

Contact-supported completion on a later date

A matching contact identifier supports a later submission. Retain both dates and check the Monday item separately.
